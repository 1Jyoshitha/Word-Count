
# 📝 Word Count App

A simple **ReactJS** application that allows users to input text and instantly see the **word count** and **character count** of their input. This is a great beginner-friendly project to practice React concepts like state, events, and dynamic rendering.

---

## 🔧 Features

- Real-time word and character count
- Live updates as the user types
- Responsive and clean UI
- Easy to use

---

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm or yarn

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/1Jyoshitha/Word-Count.git
cd Word-Count
```

2. **Install dependencies**
```bash
npm install
```

3. **Run the app**
```bash
npm start
```

The app will be available at `http://localhost:3000`.
